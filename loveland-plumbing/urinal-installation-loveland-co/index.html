    American Standard and Kohler Urinal Installation in Loveland

    American Standard and Kohler make the china we install most.     Sloan Flush Valve Installation in Loveland, CO

    Sloan Royal valves are on most commercial urinals we see. We install them with the correct inside parts kit for the bowl's rated volume, set the control stop so the flush is strong without splashing, and keep rebuild kits on the truck for later service. Optima sensor valves fit the same spud. Battery models need no wiring.

    Home Gym and Garage Urinals in Loveland, CO

    A garage urinal saves tracking dirt into the house. Unheated garages need freeze planning. Ask us about the layout.

    Sensor Urinal Installation in Loveland, CO

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    Drainage and Venting for Urinals in Loveland, CO

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. Venting stops gurgle and odor. We tie in within code distance.

    ADA Urinal Installation in Loveland

    Accessible urinals start at the carrier.     Waterless Urinal Installation in Loveland

    Waterless urinals save the most water and need the most discipline. They use a cartridge or a layer of sealing liquid that lets urine pass while blocking sewer gas, and the cartridge has to be swapped on schedule or the restroom starts to smell. Cleaning staff need a quick lesson. We show them how.
