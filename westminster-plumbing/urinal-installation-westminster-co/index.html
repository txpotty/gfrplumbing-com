    Flush Valve Urinal Installation in Westminster, CO

    Flush valve urinals are the commercial standard. A flushometer from Sloan or Zurn delivers a measured volume from a 3/4 inch supply with no tank, and it recovers instantly for the next user, which matters in a stadium or school restroom. The volume matches the fixture rating. Wrong settings stain bowls.

    American Standard and Kohler Urinal Installation in Westminster

    American Standard and Kohler make the china we install most. Models like the Washbrook and the Bardon come in versions from 0.125 to 1.0 gallons per flush, and each one needs a flush valve matched to that rating or the bowl will either splash or not rinse clean. The spec sheet makes matching easy. We order both together.

    Sensor Urinal Installation in Westminster, CO

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.

    Drainage and Venting for Urinals in Westminster, CO

    Urinal drains clog with scale, not paper. Urine leaves a hard mineral buildup inside the trap and the drain line, especially on waterless units and low-flow fixtures that send less water through, so we slope the line properly and add a cleanout where we can. A proper vent keeps odor out. We tie in within code distance.

    Sloan Flush Valve Installation in Westminster, CO

    Sloan Royal valves are on most commercial urinals we see. We install them with the correct inside parts kit for the bowl's rated volume, set the control stop so the flush is strong without splashing, and keep rebuild kits on the truck for later service. Sensor versions mount the same way. Battery models need no wiring.

    Flushometer Urinal Installation in Westminster

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handles can go left or right. ADA units need the handle within reach.

    Commercial Urinal Installation in Westminster

    Offices and restaurants want urinals that survive heavy use. Each unit goes on a carrier with new gaskets and stainless bolts, paired with a matched Sloan or Zurn valve. We check partition spacing too. Most codes want 15 inches from centerline to the side.

    Residential Urinal Installation in Westminster, CO

    Basement and garage bathrooms are where most home urinals go. A 2 inch drain, a vent tie-in and a supply sized to the valve go in, with blocking or a compact carrier. Many use 0.125 gallons per flush. That barely touches the water bill.
